Thirty Seconds homepage

Five directions for the homepage

Each one is a standalone page with the same headline, field and run as the live site. Open one, type any address, and press Enter to watch its version of the run. The run is simulated at 2x speed and nothing is sent anywhere.

1 of 5

Inline

The headline is the form. You finish the sentence with your address.

Mechanic
The field is set in headline type and its placeholder types out example companies. The run becomes an agent trace with a time for every stage.
Pick it if
You want the quietest page and the clearest signal that an engineer who builds agents made it.
To ship
Small. Restyle the field and render the existing run events as trace rows.

2 of 5

Drafting table

The page is a sheet of blueprint paper with a schematic of an agent team on it.

Mechanic
The grid lights up around the cursor. The schematic inks in over its construction lines as you type, and its title block fills in during the run.
Pick it if
You want the word “blueprint” to be something people see, with read, write and human-gate marks on show.
To ship
Medium. One SVG component and some CSS. The schematic needs a simpler form on phones.

3 of 5

Open roles

The blueprint's org chart sits on the homepage, waiting for hires.

Mechanic
With nothing typed it rotates through the three example teams. Type an address and it becomes your team with four open roles, which fill as agents are drafted.
Pick it if
You want visitors to see what they get before they try it. It takes over the job of the example links.
To ship
Medium. Reuses the OrgChart styles. It assumes four agents, and gate status is not streamed during a run today.

4 of 5

The dial

A thirty-second dial that shows a run before you start one.

Mechanic
The hand sweeps in real time. Move around the dial, or use the arrow keys, to see what the agents do at each second. During a run it is the live timer.
Pick it if
You want the page to sell the thirty-second promise and show the stages behind it.
To ship
Medium. One SVG component. Stage lengths are estimates, and it needs a state for runs that pass thirty seconds.

5 of 5

Constellation

Today's page, with scattered points that pull into a team.

Mechanic
Points drift and link up near the cursor. Start typing and they form an org chart under the field, which lights up agent by agent during the run.
Pick it if
You want the smallest change to what shipped today. The form and run console are untouched.
To ship
Small. One canvas component behind the existing page.

Each file is self-contained: React 18, Tailwind 3 with the site's tokens and config, and Inter, loaded from CDNs, so they need a network connection. Both themes work; the toggle is in each page's header.

The header and footer are stand-ins. The pill in the header steps between prototypes and is not part of any design.
